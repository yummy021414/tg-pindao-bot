## 🚀 技术特性

### 架构亮点
- **后端**：Node.js + TypeScript + Express + Telegraf
- **数据库**：JSON 文件存储（轻量级，易备份）
- **网页端**：纯 HTML5 + CSS3（无框架依赖，加载极快）
- **部署**：Docker + docker-compose


### 性能指标
- **并发能力**：5-10人同时制作相册
- **浏览承载**：50-100人同时浏览网页相册
- **响应速度**：
  - 搜索资料：< 2秒
  - 生成相册：< 10秒（含视频下载）
  - 网页加载：< 3秒（首次）

### 存储管理
- **图片**：流代理模式（不占硬盘）
- **视频**：本地缓存（7天自动清理）
- **数据库**：每3天自动备份（保留10个版本）
- **日志**：自动追加写入

## 📦 部署要求

### 系统要求
- 操作系统：Linux (Debian/Ubuntu)
- Node.js：18+
- Docker：20+
- 内存：≥ 1GB
- 硬盘：≥ 10GB（取决于相册数量）
- 网络：稳定访问 Telegram API

### 端口要求
- `3000`：网页服务器端口（需在防火墙和安全组开放）

### 环境变量
```env
BOT_TOKEN=你的机器人Token
SUPER_ADMIN_ID=超级管理员Telegram用户ID
CHANNEL_IDS=频道ID列表（逗号分隔）
DOMAIN=http://你的域名:3000
DATABASE_PATH=./data/bot.db
```

  - 返回机器人在线状态
  - 缓存相册数量
  - 运行时长
  - 版本号

### 常用命令
```bash
# 查看运行状态
docker ps | grep pindaobot

# 查看日志
docker logs -f pindaobot

# 重启服务
cd deploy && docker-compose restart

# 强制重新构建
cd deploy && docker-compose down && docker-compose build --no-cache && docker-compose up -d

# 查看错误日志
cat data/errors.log | tail -50
```

## 📊 数据流转示意

```
用户发送关键词
    ↓
机器人搜索数据库
    ↓
返回媒体组（图片/视频）
    ↓
用户可选操作：
  - 继续搜索
  - 制作相册（混搭多组资料）
  - 联系管理员
    ↓
相册生成：
  图片：保留 file_id（流代理）
  视频：下载到服务器本地
    ↓
生成网页 + 二维码 + 链接
    ↓
用户/管理员分享链接
    ↓
访客浏览网页相册
    ↓
7天后自动销毁
```
